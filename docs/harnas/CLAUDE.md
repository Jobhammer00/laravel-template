# Harness

A fixed set of rules that every new project must follow. Read every rule file
below and follow them strictly.

## Language policy

- All rules are written in English. The rule files stay English.
- The AI translates into Dutch for the developer: it communicates with the
  developer in Dutch and explains the rules in Dutch when asked. The rules
  themselves are never rewritten in Dutch.
- Throughout these rules, **"the developer"** means the person the AI is
  working with. **"The user"** is reserved for the user of the application
  being built.
- First audience is technical people. The harness must eventually also be
  usable by non-technical people.
